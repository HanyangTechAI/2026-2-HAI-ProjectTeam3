2026-10-26 기준. **상세 보고서가 아닌 핵심 현황만 정리한 짧은 요약입니다.**

- **데이터:** FFHQ-Aging 8,663장 검증과 전체 유사도 후보 검사 완료. Train 8,163 / Val 400 / Test 100. 동일인 후보는 확정 판정이 아니며, Test는 누수 후보 조사에만 사용하고 품질 선택에는 사용하지 않음. 원본을 보존하고 학습 복사본의 70+ 캡션 572건만 수정.
- **Age LoRA:** 기존 12-step 실험과 별개로 새 100-step 학습 후 300-step까지 실제 재개 완료. 총 학습 실행 363.3초, peak allocated VRAM 2,525.5MiB. 저장·무결성·재로딩 검증 완료. 연령 변환 개선 근거가 부족해 1,000-step 연장은 하지 않음.

## 사용자가 직접 확인한 결과와 미해결 문제

- **`repaired face only`:** 원본 보존은 강화됐지만 나이 변화가 사실상 보이지 않음.
- **전체 사진/crop을 다시 생성하는 방식:** 뒤 배경과 배경 인물, 표정, 옷, 자세까지 달라지거나 뭉개져 부자연스러움.
- **현재 판단:** 충분한 연령 변화와 원본 인물·장면 보존 사이의 적절한 절충점을 아직 찾지 못함. 실행·저장 성공이나 높은 ArcFace 수치만으로 실사용 가능하다고 평가하지 않음. 100-step은 후속 실험용 후보이지 채택된 연령 변환 모델이 아님.
- **다음 검토:** 무작정 학습량을 늘리기보다 얼굴·가림 영역 분리와 표정·구조를 유지하는 편집 조건을 검토하고, 사용자가 실제 사진을 직접 비교해 판단할 수 있는 방식으로 검증해야 함.
